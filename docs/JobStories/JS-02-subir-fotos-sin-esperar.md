# JS-02: Subir fotos sin esperar

- **Actor:** Fotógrafo
- **Prioridad:** MVP
- **Relacionado con:** RF-08, RF-09, RNF-08

## Job story

**Cuando** tengo cientos de fotos de una sesión para subir,
**quiero** subirlas todas juntas y que el procesamiento ocurra en segundo plano,
**para** seguir trabajando sin quedarme esperando a que se generen las miniaturas.

## Motivación

Las sesiones pueden tener muchas fotos y no quiero una pantalla bloqueada mientras se procesan.

## Resultado esperado

Puedo subir varias fotos a la vez y las miniaturas aparecen automáticamente cuando terminan de procesarse.
