## Contiene

- HT-01: Estructura del repositorio y docker-compose
- HT-02: API Gateway: punto de entrada y validación de sesión
- HT-03: Base de datos propia por servicio
- HT-04: Contratos OpenAPI por servicio
- HT-05: Broker de mensajes y eventos asíncronos
- HT-06: Procesamiento asíncrono de miniaturas
- HT-07: Almacenamiento privado de originales con enlaces temporales
- HT-08: Hash seguro de contraseñas
- HT-09: Generación de códigos aleatorios para enlaces
- HT-10: HTTPS en toda la comunicación
- HT-11: Frontend responsive en español
- HT-12: Validación de la selección orquestada por el gateway
