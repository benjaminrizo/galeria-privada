## Historia de usuario

Como **fotógrafo**, quiero **definir el precio de las fotos extra** para **ofrecer más fotos a mi cliente cuando llegue al límite**.

## Criterios de aceptación

```gherkin
# language: es
Característica: Definir el precio de las fotos extra

  Escenario: Definir precio
    Dado que estoy editando una sesión
    Cuando ingreso un precio mayor que cero para las fotos extra
    Entonces el precio queda guardado

  Escenario: Precio inválido
    Dado que estoy definiendo el precio
    Cuando ingreso un valor negativo
    Entonces el sistema lo rechaza
```
