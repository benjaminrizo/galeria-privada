## Historia de usuario

Como **fotógrafo**, quiero **que el cliente solo vea versiones reducidas de mis fotos** para **proteger mis archivos originales**.

## Criterios de aceptación

```gherkin
# language: es
Característica: El cliente solo ve versiones reducidas

  Escenario: Galería con versiones reducidas
    Dado que un cliente abre su galería
    Cuando se cargan las imágenes
    Entonces solo recibe versiones reducidas, nunca el archivo original

  Escenario: Acceso directo al original
    Dado que alguien intenta abrir la ruta de un original sin un enlace temporal válido
    Cuando el sistema recibe la petición
    Entonces el acceso es denegado
```
