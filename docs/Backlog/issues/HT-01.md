## Historia técnica

Dejar una estructura de carpetas por servicio y un `docker-compose.yml` que levante todo el sistema.

## Criterios de aceptación

- [ ] Existe una carpeta por servicio (gateway, ms-auth, ms-galerias, ms-media, ms-seleccion, ms-notificaciones).
- [ ] `docker-compose up` levanta todos los servicios y sus bases de datos.
- [ ] El README explica cómo ejecutar el proyecto.
