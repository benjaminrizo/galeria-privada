## Historia de usuario

Como **fotógrafo**, quiero **que el sistema genere miniaturas automáticamente** para **no tener que prepararlas yo y que la galería cargue rápido**.

## Criterios de aceptación

```gherkin
# language: es
Característica: Miniaturas automáticas

  Escenario: Miniatura generada
    Dado que subí una foto
    Cuando el sistema termina de procesarla en segundo plano
    Entonces la foto aparece con su miniatura en la galería

  Escenario: Foto en procesamiento
    Dado que subí una foto que aún se procesa
    Cuando miro la galería
    Entonces la foto aparece marcada como en procesamiento
    Y no tengo que esperar para seguir subiendo otras

  Escenario: Fallo de procesamiento
    Dado que una foto falla al procesarse
    Cuando el sistema detecta el error
    Entonces esa foto se marca con error
    Y las demás fotos no se ven afectadas
```
