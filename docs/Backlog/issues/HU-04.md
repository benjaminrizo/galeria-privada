**Épica:** 2 · Sesiones y galerías
**Prioridad:** MVP
**Requerimiento:** RF-04
**Job story:** JS-01

## Historia de usuario

Como **fotógrafo**, quiero **crear una sesión con nombre, datos del cliente y límite de fotos incluidas** para **definir el paquete que contrató mi cliente**.

## Criterios de aceptación

```gherkin
# language: es
Característica: Crear una sesión

  Escenario: Creación exitosa
    Dado que inicié sesión
    Cuando completo nombre, datos del cliente y un límite mayor que cero
    Entonces la sesión se crea con su galería en estado borrador

  Escenario: Límite inválido
    Dado que estoy creando una sesión
    Cuando ingreso un límite de cero o negativo
    Entonces veo un mensaje de error
    Y la sesión no se crea

  Escenario: Nombre vacío
    Dado que estoy creando una sesión
    Cuando dejo el nombre vacío
    Entonces el sistema me pide completarlo
```
