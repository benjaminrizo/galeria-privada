## Historia de usuario

Como **cliente**, quiero **abrir el enlace de mi galería sin crear cuenta** para **ver mis fotos de inmediato desde mi celular**.

## Criterios de aceptación

```gherkin
# language: es
Característica: Acceso del cliente con el enlace, sin cuenta

  Escenario: Enlace válido de una galería publicada
    Dado que el fotógrafo publicó mi galería
    Cuando abro mi enlace
    Entonces veo mis fotos sin que me pidan registrarme ni iniciar sesión

  Escenario: Código inexistente
    Dado que abro un enlace con un código que no existe
    Cuando el sistema lo busca
    Entonces veo un mensaje de galería no encontrada
    Y no se revela información de ninguna otra galería

  Escenario: Galería aún en borrador
    Dado que la galería está en borrador
    Cuando abro su enlace
    Entonces veo un mensaje de galería no disponible
```
