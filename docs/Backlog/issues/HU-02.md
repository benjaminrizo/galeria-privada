## Historia de usuario

Como **fotógrafo**, quiero **que el sistema genere un enlace privado y único para cada galería** para **compartirlo con mi cliente sin que otras personas puedan adivinarlo**.

## Criterios de aceptación

```gherkin
# language: es
Característica: Enlace privado y único por galería

  Escenario: Se genera el enlace al crear la galería
    Dado que creo una sesión con su galería
    Cuando el sistema guarda la galería
    Entonces se genera un enlace con un código aleatorio largo

  Escenario: Enlaces distintos por galería
    Dado que tengo dos galerías
    Cuando consulto sus enlaces
    Entonces cada una tiene un código diferente

  Escenario: Copiar el enlace
    Dado que estoy en el detalle de una galería
    Cuando pulso el botón de copiar enlace
    Entonces el enlace queda copiado en mi portapapeles
```
