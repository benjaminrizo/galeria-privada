## Historia de usuario

Como **fotógrafo**, quiero **subir varias fotos a la vez a una sesión** para **cargar toda la sesión sin hacerlo foto por foto**.

## Criterios de aceptación

```gherkin
# language: es
Característica: Subir varias fotos a una sesión

  Escenario: Subida múltiple
    Dado que estoy en el detalle de una sesión
    Cuando selecciono varias fotos y las subo
    Entonces todas quedan asociadas a esa sesión

  Escenario: Formato no permitido
    Dado que selecciono un archivo que no es una imagen admitida
    Cuando intento subirlo
    Entonces el sistema lo rechaza con un mensaje claro
    Y las demás fotos se suben normalmente
```
