## Historia de usuario

Como **cliente**, quiero **dejar un comentario de retoque en cada foto que elegí** para **que el fotógrafo entienda qué quiero sin explicarlo por otro chat**.

## Criterios de aceptación

```gherkin
# language: es
Característica: Comentario de retoque por foto

  Escenario: Comentar una foto seleccionada
    Dado que tengo una foto seleccionada
    Cuando escribo un comentario y lo guardo
    Entonces el comentario queda asociado a esa foto

  Escenario: Editar un comentario
    Dado que ya comenté una foto y aún no envié mi selección
    Cuando modifico el comentario
    Entonces se guarda la nueva versión

  Escenario: Comentar tras el envío
    Dado que ya envié mi selección
    Cuando intento editar un comentario
    Entonces el sistema no me lo permite
```
