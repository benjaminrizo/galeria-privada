**Prioridad:** MVP

## Historia de usuario

Como **cliente**, quiero **enviar mi selección final** para **que el fotógrafo la reciba y no haya que repetir nada**.

## Criterios de aceptación

```gherkin
# language: es
Característica: Enviar la selección final

  Escenario: Envío exitoso
    Dado que tengo fotos seleccionadas
    Cuando confirmo el envío de mi selección
    Entonces la selección queda registrada y bloqueada
    Y veo un mensaje de confirmación

  Escenario: Intentar cambiar tras el envío
    Dado que ya envié mi selección
    Cuando intento marcar o desmarcar una foto
    Entonces el sistema no me lo permite

  Escenario: Envío sin fotos
    Dado que no he seleccionado ninguna foto
    Cuando intento enviar
    Entonces el sistema me indica que debo elegir al menos una
```
